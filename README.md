# Malecns Warhammer — Behavioral Sandbox

Рабочая браузерная песочница для исследования поведения юнитов, версия 0.4.
Это авторская условная симуляция, а не реализация правил Warhammer 40,000 / Kill Team.

## Запуск

Требуется Node.js с поддержкой ES modules и встроенного test runner.

    npm start

Откройте адрес, который напечатает сервер (по умолчанию http://127.0.0.1:4177).
Внешние библиотеки, платные API и загрузка моделей не нужны.

    npm test


## Теперь MaleCNS действительно участвует в поведении

В проект включён **реальный подграф MaleCNS v1.0**: 319 нейронов, 21 288 направленных
связей и 102 445 синаптических контактов. Веса — исходные целочисленные количества
контактов, а не случайная сеть. Это цепь реакции на угрозу LC4/LPLC2 → DNp01/02/04/11,
выделенная из опубликованного пакета [slvDev/esp32-ai-fly](https://huggingface.co/slvDev/esp32-ai-fly).
Идентификаторы нейронов проверены по таблице аннотаций, исходные файлы — по SHA-256.
Граф уже включён в приложение; при обычном запуске интернет не нужен.

Это **гибрид**: коннектом даёт рефлекс отступления, а тактический алгоритм выбирает
цели, путь и огонь. У каждой миниатюры собственная память нейронной активности.
Фракция и роль влияют на порог реакции, а не заменяют анатомию выдуманным «мозгом орка».

В настройках каждой группы доступны три режима:

| Режим | Что управляет юнитом |
|---|---|
| MaleCNS + тактика | Реальный граф может прервать план и выбрать отход |
| Контроль: связи отключены | Те же входы и динамика; передача между нейронами отключена |
| Только тактика | Исходный алгоритм полезности, без нейронной динамики |

После смены режима нажмите **«Создать поле»**. В инспекторе есть входы и выходы
по сторонам, порог рефлекса, история сигнала и все 319 ячеек активности.
При наведении отображаются тип и исходный body ID. Ячейки расположены условно,
это не геометрия мозга. Цвет показывает вычисленную активность, не запись эксперимента.
Кнопка «Шаг» выполняет один такт боя; на активацию юнита приходится 4 нейронных шага.
Простое открытие инспектора, редактирование профиля и предварительный расчёт решения
не продвигают нейронное время.

### Что биологическое, а что задано программой

Анатомические данные: body ID, тип, сторона, направленные связи и количества контактов.
Динамика: дискретная leaky-rate модель с tanh, gain 0.7, leak 0.5, amplitude 0.8.
Каждый вес нормируется по полному входящему числу контактов целевого нейрона
в исходной выборке из 48 311 нейронов; удалённые нейроны дают нулевой вклад.

Вход — видимая близкая угроза из игровой сцены. Лево/право задано относительно
направления развёртывания (A смотрит на восток, B на запад). Выход — средняя
активность четырёх DN на каждой стороне. Программный порог зависит от осторожности
и агрессии. При превышении порога и наличии менее опасной позиции выбирается отход.

Мы не моделируем весь CNS, знаки нейромедиаторов, спайки, сенсорную физиологию,
обучение или биологически достоверное поведение мухи. Перенос сигнала на тактику
Warhammer — наша конструкция. Нейросеть не обучалась выигрывать бой.

### Воспроизводимость данных и эксперименты

    npm run data:fetch
    npm run data:build
    npm run benchmark

Первая команда загружает около 16 МБ публичных исходных данных в локальный кэш,
проверяет закреплённые размеры и SHA-256 и извлекает подграф. Вторая повторяет
извлечение из кэша без сети. Третья записывает контрольные прогоны в data/benchmark.json.
Токен neuPrint не требуется. Ошибка скачивания или контрольной суммы останавливает
импорт; синтетической подмены данных нет.

В первоначальном прогоне версии 0.2 на 6 одинаковых seed команда A с нейрорефлексом проиграла
тактическому контролю все 6 боёв. При отключённых связях результаты совпали
с обычным алгоритмом (4 победы A из 6). Это небольшой диагностический набор,
не оценка общей силы алгоритма. В версии 0.2 постоянный высокий сигнал приводил к частым отступлениям; ниже описано исправление в 0.3.
После расхождения действий расход случайных чисел также расходится.

В отдельной одинаковой контактной сцене рабочий граф выбирает отход,
а отключённый граф и обычная тактика выбирают атаку. Этот причинный контроль,
направленность сигнала, задержка передачи, границы активности и сохранение памяти
проверяются тестами. Полный benchmark и контрольные входы включены в репозиторий.

## Что изменилось в 0.4

Нейронный отход ищет путь в пределах **оставшегося лимита реакции**:
не больше двух клеток на первой активации и одной на второй. Каждый следующий
шаг должен не увеличивать оценку угрозы; конечная клетка должна снижать её.
Проверяются все короткие маршруты, включая разные пути к одной клетке.
Если подходящего пути нет, действует обычная тактика. Дальний тактический
отход при низком HP оценивается отдельно и не получает эту гарантию.

Оценка угрозы — сумма базового урона видимых противников, достающих клетку,
с коэффициентом 0.6 для дальнего огня по укрытию. Вплотную укрытие не защищает;
это теперь одинаково учитывается при оценке угрозы, выборе атаки и расчёте урона.
Оценка относится к полю **в момент выбора**, без вероятности попадания, будущих
перемещений врага и гарантии выживания. Перед следующим действием путь пересчитывается.

В инспекторе появился блок **«Влияние рефлекса»**: обычный выбор на том же поле,
выбранное действие, угроза сейчас / после первого шага / в конце пути.
Изменением считается другая цель атаки или другой первый шаг, а не смена
названия действия. Если рефлекс и тактика выбрали ту же клетку, это показано явно.
Сравнение касается одного решения, а не альтернативной истории всей партии.

Анатомический граф, динамика сети и ограничитель эпизодов не изменились.

### Контрольный прогон 0.4

Повторён прежний набор из 72 боёв без подбора seed и параметров.

| Набор | MaleCNS: победы | Отключённые связи: победы | Тактика: победы |
|---|---:|---:|---:|
| 6 прежних seed, обе стороны | 3 / 12 | 6 / 12 | 6 / 12 |
| 6 дополнительных seed, обе стороны | 2 / 12 | 6 / 12 | 6 / 12 |

В 24 боях с MaleCNS выполнено **165 нейронных отходов**; **156** изменили
первое действие по сравнению с тактикой в том же состоянии. В 101 решении
активный рефлекс не нашёл подходящего пути и сохранил тактический выбор.
Нарушений ограничения длины, роста угрозы на маршруте или отсутствия
снижения в его конце — **0**. Это проверки в момент решения, не гарантия
результата после хода противника.

Побед 5 из 24 против 4 из 24 в версии 0.3. Преимущество над обычной
тактикой не показано; такой диагностический набор не доказывает общую силу модели.
Контактный тест при стандартной чувствительности: первый нейронный отход
вместо атаки, 2 отхода за 12 тактов, 15 HP у A в конце; два контрольных режима
дают одинаковую последовательность и 0 HP. Это результат одной фиксированной сцены.

Отчёт: data/benchmark.json. Предыдущие результаты сохранены в
data/benchmark-v0.3.json и data/benchmark-v0.2.json. Теперь действия учитываются
до исполнения, в том числе у юнитов, погибших позже в том же такте;
счётчик атак в старом отчёте мог пропускать такие действия.

## Ограничитель реакции и эксперименты, добавленные в 0.3

Рефлекс больше не перехватывает каждый ход при постоянной угрозе.
Игровой контроллер допускает до **2 действий** за эпизод, затем возвращает
управление тактике на **5 активаций**. Для следующего эпизода сигнал должен
опуститься до 65% порога и затем снова пересечь порог включения.
Обычный тактический отход при малом HP остаётся отдельным действием.

В инспекторе показаны фазы «Готов → Реакция → Пауза → Ожидание» и число
нейронных отходов. Слайдер **«Чувствительность MaleCNS»** меняет усиление
выхода от 0× до 2×, по умолчанию 1×. При 0× сеть продолжает вычисляться,
но не перехватывает действия. Это настройка игрового адаптера: исходные
нейроны, веса и динамика не изменяются.

### Быстрый эксперимент

1. Нажмите **«Тест рефлекса»**. Откроется фиксированная сцена 1 на 1:
   два разведчика Astartes, группа A с MaleCNS, B с обычной тактикой.
2. Нажмите **«Шаг»** и выберите A-01. Наблюдайте за входом, выходом,
   фазой рефлекса и маршрутом.
3. Кнопка **«Сравнить 3 режима»** запускает три независимые копии
   контактной сцены максимум на 12 тактов и показывает первое действие,
   нейронные отходы, урон, HP и последовательность действий.
   Текущий бой ставится на паузу, его состояние не заменяется.
4. Измените чувствительность и повторите сравнение.
   Оно берёт чувствительность выбранного юнита; остальные условия
   контактной сцены фиксированы (агрессия 0.4, осторожность 1, приоритет
   миссии 0, две одинаковые модели разведчика).
   «Открыть тестовую сцену» в сравнении сохраняет выбранную чувствительность A.

Контактная сцена доступна также в списке «Сцена». Для неё используется
фиксированное открытое поле; seed определяет случайности боя.
Выбранные фракции и режимы применяются кнопкой «Создать поле».
Полный сценарий контроля точек по-прежнему содержит 5 юнитов с каждой стороны.

### Контрольный прогон 0.3

Проверено 72 боя: 12 фиксированных seed × обе стороны для испытуемого режима ×
3 режима. Шесть seed взяты из 0.2, шесть добавлены до оценки.
В каждом бою противник использует обычную тактику, обе фракции — Astartes.

| Набор | MaleCNS: победы | Отключённые связи: победы | Тактика: победы |
|---|---:|---:|---:|
| 6 прежних seed, обе стороны | 2 / 12 | 6 / 12 | 6 / 12 |
| 6 дополнительных seed, обе стороны | 2 / 12 | 6 / 12 | 6 / 12 |

На прежних шести сценах для группы A среднее число **нейронных** отходов
снизилось с 51.7 до 10 за бой; максимальная непрерывная серия теперь 2.
Это устраняет захват управления одним высоким сигналом, но **преимущества
в бою пока нет**. Здесь нет обучения или подбора параметров оптимизатором.

набор, а не статистическое доказательство общей силы модели.

Этот исторический отчёт: data/benchmark-v0.3.json. Команда npm run benchmark
пересчитывает data/benchmark.json по текущим правилам версии 0.4.

### Снимки сцен

Формат v4 сохраняет состояние сети, чувствительность и состояние игрового
рефлекса: фазу, остаток реакции или восстановления и число эпизодов.
Продолжение в рамках v4 воспроизводится точно. Сцены v1/v2/v3 загружаются
с сообщением о миграции: дальнейшее поведение вычисляется по правилам v4.
У v3 сохраняются контактная сцена, нейронная память и состояние рефлекса.
У v2 сохраняется нейронная память, рефлекс начинает с готового состояния.
Сцены v1 остаются в режиме обычной тактики.

## Что работает

- Воспроизводимый генератор 32×22: руины, промышленная зона и каменистое плато.
- Четыре авторских профиля фракций: Space Marines, Orks, Necrons, Tyranids.
- Пять агентов на сторону (один в контактном тесте), три роли: разведчик, штурмовик и стрелок.
- Движение по проходимым клеткам, блокирование линии огня стенами, укрытия.
- Выбор действия по полезности с агрессией, осторожностью и приоритетом миссии.
- Координация: назначенные сектора и штраф за избыточное скопление союзников у цели.
- Пауза, шаг, скорость 1×/2×/4×, сброс исходного эксперимента.
- Инспектор с объяснениями, сравнение вариантов, редактирование профиля.
- Редактор препятствий до начала боя с защитой проходов.
- Сохранение/загрузка JSON со сценой, текущим состоянием и состоянием генератора случайных чисел.
- Отображение маршрутов, угрозы выбранному юниту и журнала боевых событий.

Пробел запускает/останавливает, стрелка вправо выполняет шаг, если фокус вне элементов ввода.
Выбирать юниты можно на карте или кнопками списка подразделений.

## Модель боя и границы

Один такт даёт каждому живому юниту одно действие; порядок активации перемешивается воспроизводимо.
Перемещение — 1 клетка по четырём направлениям. Дальность — манхэттенская.
Атака требует линии видимости. Стрелковая атака имеет вероятность попадания 83%, соседняя — 94%.
Укрытие снижает дальний урон на 40%; урон имеет небольшую случайную вариацию.
Эти параметры являются механикой прототипа и не взяты из официальных datasheets.

Точка контролируется юнитами на самой точке или соседней клетке, если нет противника в этом радиусе.
Каждая контролируемая точка даёт 1 очко за такт. Победа: 65 очков или уничтожение противника.
На 180-м такте победитель определяется счётом, при равном счёте — ничья.

Тактический алгоритм имеет полную информацию о поле; нейронный вход учитывает только
видимые угрозы. Тумана войны, камеры и физического восприятия пока нет.
Планирование оценивает текущую ситуацию, без глубокого поиска будущих ходов или обучения.
Фракции различаются параметрами; уникальные официальные способности не реализованы.
Один маркер — один условный юнит. Отдельные бойцы внутри отряда не моделируются.

Сохранение создаёт снимок, а не запись всей партии. Нейронная память, модель и история сигнала сохраняются. Исторический журнал боя после загрузки начинается заново;
дальнейший бой при одинаковых действиях пользователя воспроизводится.
Сброс после импорта возвращает к импортированному состоянию. Новый бой создаётся кнопкой «Создать поле».
Изменения seed / ландшафта / фракций / режима управления применяются при создании нового поля.
Настройки профиля агента действуют сразу. Изменения профиля до первого такта включаются в исходную сцену.
После начала боя смена профиля не перезаписывает исходную сцену для сброса.

## Архитектура

- dist/data/malecns-escape.mjs — закреплённый анатомический подграф и его SHA-256.
- dist/neural.mjs — динамика сети, независимая от браузера и боя, контроль без связей.
- dist/reflex.mjs — игровой ограничитель реакции; отдельный от биологического графа контракт.
- dist/experiments.mjs — воспроизводимое сравнение трёх режимов на контактной сцене.
- tests/decision.test.mjs — безопасность короткого маршрута, сравнение с тактикой, учёт оставшихся действий и миграция v3.
- tests/reflex.test.mjs — ограничения реакции, чувствительность, миграции и контактная сцена.
- scripts/import-malecns.mjs — проверка источников, декодирование FCL/LZ4 и извлечение.
- data/ — происхождение, лицензия, манифест и результаты сравнения.
- tests/neural.test.mjs — идентичность данных, причинные контроли, нейронная память.

- dist/engine.mjs — чистое ядро. Данные, RNG, карта, LOS, поиск пути, принятие решений, переход состояния, валидация JSON.
- dist/app.mjs — DOM, управление симуляцией и рисование Canvas.
- dist/index.html, dist/style.css — интерфейс без сборки и внешних зависимостей.
- server.mjs — локальный сервер статических файлов.
- tests/engine.test.mjs — инварианты генератора и боя, детерминизм, влияние профиля, сохранение/загрузка.

Основные экспортируемые функции:

    const state = createSimulation({seed: '40721', factionA: 'marines', factionB: 'orks'});
    const intent = decideUnit(state, state.units[0]);
    stepSimulation(state);
    const snapshot = exportScene(state);
    const restored = importScene(snapshot);

decideUnit возвращает намерение: type, target / objective / destination, route,
score, reason, alternatives, evaluatedAt, origin. counterfactual содержит обычный
выбор на том же поле и признак изменения первого действия. Для нейронного отхода
routeSafety содержит оценку угрозы и лимит пути. Функция не выполняет действие, не продвигает нейронную модель и не обращается к DOM.
Нейронная память продвигается внутри stepSimulation перед выбором действия.
Для диагностики stepSimulation(state, (decision, unit, board) => { ... }) вызывает
наблюдатель перед каждым действием, в том числе для юнита, который погибнет позже
в этом такте. Наблюдатель не должен менять переданные объекты.
В режиме физического адаптера нужно отдельно вызывать stepBrain с наблюдениями сенсоров.

## Переход к физическому прототипу

Пока реализован только цифровой симулятор. Камера, сетевой API и моторы не подключены.

1. Сначала отделить поток наблюдений от истинного состояния мира: доверие сенсорам, задержка,
   пропавшие метки, ручная коррекция. Подавать только доступную агенту информацию.
2. Адаптер камеры преобразует наблюдения в координаты мира после калибровки.
   Клетки прототипа не являются миллиметрами; масштаб и геометрия подставок требуют отдельного слоя.
3. Использовать decideUnit для выдачи намерения. В реальном режиме stepSimulation не должен
   имитировать фактическое перемещение вместо подтверждения от устройства.
4. Человек выполняет действие и подтверждает результат. Это первая проверяемая аппаратная версия.
5. Затем подключить исполнительный контроллер: маршрут, скорости, границы поля, обнаружение препятствий,
   подтверждение выполнения, аварийная остановка и безопасное состояние при потере связи.
6. Небольшой компьютер с Node.js сможет выполнять это ядро; конкретное железо выбирается
   после измерений камеры, задержки и нагрузки. Для микроконтроллера потребуется отдельный порт или
   роль исполнителя команд от основного компьютера.

Следующая содержательная итерация: сравнение поведения на наборах одинаковых сцен и более богатые
профили конкретных типов юнитов, затем модель восприятия и физический адаптер.


## Автономная версия

Готовый malecns-warhammer.html открывается в обычном браузере двойным щелчком, без сервера и интернета.
Для пересборки автономной версии после редактирования исходников:

    npm run export

Файл появится в standalone/malecns-warhammer.html. Исходный модуль engine.mjs остаётся независимым.
Проверено: 40 тестов ядра, нейронной модели, игрового рефлекса и выбора маршрута,
72 контрольных боя, синтаксис JavaScript и автономного пакета. Визуальная проверка в браузере
из среды разработки не выполнена: доступ к локальному превью недоступен.
