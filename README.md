# Malecns Warhammer — Behavioral Sandbox

Браузерная песочница поведения юнитов, версия **0.5**. По умолчанию обе группы
управляются нейронным контроллером на анатомическом подграфе MaleCNS.
Это авторская условная симуляция, не реализация правил Warhammer 40,000 / Kill Team.

## Запуск

Готовый **standalone/malecns-warhammer.html** открывается двойным щелчком,
без сервера, интернета, платных API и загрузки модели.

Для работы с исходниками нужен Node.js с ES modules и встроенным test runner:

    npm start
    npm test
    npm run benchmark
    npm run export

Сервер печатает адрес, по умолчанию http://127.0.0.1:4177. Последняя команда
пересобирает автономный HTML; размер версии 0.5 — около 10.6 МБ.

## Главное изменение: сеть выбирает команды

В режиме **«MaleCNS · нейронное управление»** действие выбирается по активности
выходных нейронов. У каждого юнита своя активность **11 436 нейронов** и собственное
направление взгляда. Общая анатомия содержит **1 687 031 направленную связь**,
или **10 931 415 исходных синаптических контактов**.

Сеть определяет конкуренцию команд: вперёд, назад, повернуть влево, повернуть
вправо, ждать. Тактический алгоритм полезности, поиск пути и назначенные сектора
в этом режиме не участвуют. Старый короткий рефлекс не ограничивает управление
двумя действиями: нейронный контроллер действует на каждой активации юнита.

Остаётся **программный адаптер восприятия и тела**:

- Он кодирует видимых противников, ориентиры и соседние препятствия в четыре
  входа: угроза L/R и объект L/R. Используются LC4/LPLC2 и LC10.
- Агрессия усиливает заметность врагов, осторожность — угрозу, приоритет миссии —
  ориентиры. Фоновый сигнал объекта 0.035 на каждой стороне задаётся программой.
  Это условная проекция сцены, не реконструкция сетчатки.
- Выходы DNa02, DNp09, MDN и DNp01/02/04/11 переводятся в оценки команд.
  Масштабы выровнены по реакции на симметричные входы 0.5; коэффициенты и порог
  ожидания 0.06 заданы разработчиком. Обучения на результатах боя нет.
- Стены, границы карты и занятые клетки исключают невозможные перемещения.
  Поворот меняет взгляд на 45°; движение остаётся по четырём направлениям сетки,
  с округлением взгляда к ближайшей оси.
- Команда «вперёд» превращается в атаку, когда перед юнитом есть доступная цель.
  **Конкретный противник выбирается правилом:** ближайший видимый враг в радиусе
  оружия и секторе ±45°; при равенстве — по ID. Направление сектора определяет
  сеть, но отдельного нейронного выбора личности цели пока нет.
- Правила боя рассчитывают попадание, урон, контроль точек и победу.

Это расширение автономности, **не доказательство разумной стратегии**.
Необученная сеть может отступать, вращаться, менять направление или застревать.
Здесь нет планирования партии, знания правил Warhammer или модели сознания мухи.
Гарантии безопасного короткого отхода старого режима не относятся к новому.

## Как посмотреть

1. Откройте HTML и нажмите «Шаг». В исходной сцене 5 на 5 обе группы уже используют
   нейронное управление. Черта рядом с маркером показывает направление взгляда.
2. Выберите юнит. Инспектор показывает команды, их оценки, недоступные движения,
   входы и выходы сети. Оценки — сигналы нашего декодера, не вероятности.
3. Кнопка **«Нейронное управление ↗»** открывает фиксированный контактный тест:
   один разведчик Astartes с нейронным контроллером против такого же юнита с тактикой.
4. **«Сравнить режимы»** запускает три независимые копии контактной сцены максимум
   на 12 тактов. Для выбранного нейронного юнита сравниваются рабочая сеть,
   отключённые связи и тактика. Для старого режима сравниваются короткий рефлекс,
   его контроль без связей и тактика. Текущий бой ставится на паузу и сохраняется.
5. Слайдер чувствительности меняет усиление команд от 0× до 2×. При 0× нейронный
   юнит ждёт, хотя сеть продолжает вычисляться. Изменение трёх входных приоритетов
   влияет на наблюдения со следующего такта. Просмотр инспектора не двигает время.

Сравнение берёт чувствительность выбранного юнита. Остальные условия фиксированы:
seed reflex-01, агрессия 0.4, осторожность 1, приоритет миссии 0, одинаковые фракции
и роли, противник B использует тактику. «Открыть тестовую сцену» сохраняет выбранную
чувствительность A.

В инспекторе показана равномерная выборка 319 из 11 436 нейронов, с типом,
стороной и body ID при наведении. Это условная сетка, не форма мозга.
В компактном рефлексе показаны все 319 нейронов. График под сеткой показывает
выходы цепи угрозы; отдельные двигательные выходы и оценки команд находятся выше.

## Режимы

| Режим | Выбор действия |
|---|---|
| MaleCNS · нейронное управление | Выходы расширенной сети через двигательный декодер |
| Нейронное управление · без связей | Те же входы; передача между нейронами отключена, из нулевого состояния команды отсутствуют |
| MaleCNS + тактика | Компактная цепь угрозы может прервать обычный тактический выбор |
| Контроль: связи отключены | Компактные входы активны, выходов нет; действует тактика |
| Только тактика | Алгоритм полезности без нейронной динамики |

Выбор режима или фракции применяется кнопкой «Создать поле».
Различия фракций и ролей — авторские параметры восприятия и игровых характеристик,
не разные биологические коннектомы и не официальные способности Warhammer.

## Данные и границы модели

Обе сети получены из закреплённого пакета
[slvDev/esp32-ai-fly](https://huggingface.co/slvDev/esp32-ai-fly/tree/d36ff5e192da832c4348ab509d150357cb70ddd8),
основанного на MaleCNS v1.0. Исходная выборка содержит 48 311 нейронов,
9 462 135 связей и 49 481 754 контакта. Это уже подграф центральной нервной системы.

| Модель | Нейроны | Связи | Контакты |
|---|---:|---:|---:|
| Расширенное нейронное управление | 11 436 | 1 687 031 | 10 931 415 |
| Короткий рефлекс | 319 | 21 288 | 102 445 |

Для расширенной модели взяты входы LC4/LPLC2 и LC10, выходные популяции
DNa01/DNa02/DNp09/MDN и DNp01/02/04/11, а также все промежуточные нейроны
на путях от этих входов к этим выходам длиной до трёх связей.
После отбора сохранён полный индуцированный граф между выбранными нейронами,
без порога количества контактов. DNa01 входит в граф, но текущий декодер
руления читает DNa02. Каждый нейрон сохраняет исходный body ID и аннотации.

Динамика — дискретная leaky-rate модель с tanh, gain 0.7, leak 0.5,
амплитудой входа 0.8 и состоянием float32. Веса — исходные положительные
количества контактов, нормированные по полному входящему числу контактов
целевого нейрона в исходной выборке из 48 311 клеток. Удалённые клетки
дают нулевой вклад. На активацию юнита выполняются 8 нейронных шагов
в расширенной модели и 4 в компактной.

Анатомия реальна; вычисленная активность, сенсорная проекция, калибровка и команды —
наша модель. Не моделируются знаки нейромедиаторов, торможение, спайки, морфология,
полная сенсорная физиология и обучение. Поэтому движение маркера нельзя
интерпретировать как поведение настоящей мухи.

Для выбора популяций использованы исследования
[descending motor networks](https://www.nature.com/articles/s41586-024-07523-9)
и [steering control](https://pmc.ncbi.nlm.nih.gov/articles/PMC12279373/).
Соответствие популяций игровым командам не воспроизводит целиком их биологические
функции: эффект зависит от контекста и других частей нервной системы.

### Воспроизведение данных

    npm run data:fetch
    npm run data:motor
    npm run data:build

data:fetch загружает закреплённые FCL/CSV/circuit файлы, проверяет размер и SHA-256
и извлекает компактную сеть. data:motor строит расширенную модель из этого кэша.
data:build повторяет только компактное извлечение. Токен neuPrint не нужен.
При неверной контрольной сумме импорт останавливается; синтетической подмены нет.

Расширенный граф хранится в CSR: смещения строк uint32, пары «источник uint16,
контакты uint16», всего 6 793 872 байта до base64. Манифесты содержат SHA-256,
счётчики и описание выборки. Повторное извлечение проверено: идентификатор модели
2e00fbe4528b5ba23cbbcdb40aa94ee26772d1bf7c6b8ce7cfe14888029f3d89.

Исходные данные: FlyEM / HHMI Janelia, University of Cambridge, MRC LMB,
Google Research; [MaleCNS](https://male-cns.janelia.org/), CC BY 4.0.
Полные сведения и изменения: [data/MALECNS-ATTRIBUTION.md](data/MALECNS-ATTRIBUTION.md).
Лицензия данных отдельна от MIT-лицензии кода. Проверен опубликованный пакет
FCL/CSV/circuit, а не новая выгрузка исходного 1.1 ГБ Feather.

## Исправление движения между укрытиями

Найденная в 0.4 петля была ошибкой **обычной тактики**. Поиск отхода давал бонус
за соседнее укрытие, но исключал текущую клетку. Поэтому два равноценных укрытия
могли бесконечно сменять друг друга даже после окончания нейронного рефлекса.

Теперь текущая клетка также рассматривается: равное по безопасности соседнее
укрытие проигрывает ей из-за цены перемещения. Более выгодная позиция остаётся
доступной. Регрессионные тесты проверяют обе ситуации и воспроизводят контактную
сцену до 30-го такта. Это исправляет конкретную ошибку; оно не гарантирует
отсутствие любых колебаний у нового необученного контроллера.

## Проверки и результаты 0.5

**57 тестов** проверяют ядро, обе сети, причинное отключение связей, направленность
сигналов, калибровку, независимость памяти, поворот и запрет невозможных действий,
сохранение/загрузку, миграции и петлю укрытий. Дополнительно проверен бой десяти
нейронных агентов в течение 20 тактов, включая корректность координат и сохранения.

В фиксированной контактной сцене расширенная сеть выдала **12 двигательных
команд**, нанесла 0 урона и сохранила 15 HP у A после 12 тактов.
При отключённых связях: 0 команд, 0 урона, 0 HP; тактика: 5 урона, 0 HP.
Сеть сначала отступала, затем двигалась вперёд и повернула.
Это причинная демонстрация влияния связей, не оценка силы стратегии.

Прежний benchmark короткого рефлекса повторён на 72 боях:
12 seed × обе стороны испытуемого режима × 3 режима, одинаковые фракции.
Результаты: 5 побед из 24 у рефлекса, 12 из 24 у каждого контрольного режима.
165 нейронных отходов, 156 изменённых первых действий, 101 заблокированное
рефлекторное решение; нарушений условий короткого маршрута — 0.
Эти 72 боя относятся к **старому гибридному режиму**, не к расширенной сети.

Текущий отчёт: [data/benchmark.json](data/benchmark.json).
Предыдущие: data/benchmark-v0.4.json, data/benchmark-v0.3.json, data/benchmark-v0.2.json.
В отчёте указаны отдельные боковые пробы и время их выполнения.
После расхождения действий расход RNG тоже расходится.
Подбора seed, оптимизации на победы или обучения в benchmark нет.

Синтаксис модулей и автономного пакета проверен. Автоматизированная визуальная
проверка в настоящем браузере в текущей среде недоступна.

## Короткий рефлекс и тактика

Старый гибридный режим сохранён для сравнения. Цепь LC4/LPLC2 → DNp01/02/04/11
получает близкую видимую угрозу относительно направления развёртывания.
При превышении программного порога она может выбрать до двух действий отхода,
затем следует пять активаций восстановления и ожидание спада до 65% порога.

Рефлекторный маршрут укладывается в оставшийся лимит одного или двух шагов.
На каждом шаге оценка угрозы не растёт, в конце строго снижается.
Если такого пути нет, действует тактика. Оценка — сумма базового урона видимых
противников в радиусе атаки, с коэффициентом 0.6 для дальнего огня по укрытию.
Она не предсказывает ход врага, попадания или выживание.
Обычный тактический отход при малом HP имеет отдельные правила.

Блок «Влияние рефлекса» сравнивает первый физический шаг или цель атаки с обычным
тактическим выбором на том же поле. Это сравнение одного решения, не всей
альтернативной партии. В новом нейронном режиме блока нет: тактика не вызывается.

## Карта и игровые правила

- Воспроизводимое поле 32×22: руины, промышленная зона, каменистое плато.
- Space Marines, Orks, Necrons, Tyranids; роли разведчика, штурмовика и стрелка.
- Пять юнитов на сторону; в контактном тесте один.
- Один шаг, поворот, атака или ожидание за активацию. Стены закрывают линию огня,
  дальний урон по укрытию снижен на 40%; вплотную защита укрытия не действует.
- Три точки контроля. Радиус захвата — одна клетка без врагов рядом.
  Победа: 65 очков, уничтожение противника или больший счёт после 180 тактов.
- Пауза, шаг, скорости 1×/2×/4×, сброс, редактирование карты до первого такта.
  Скорость ограничена временем расчёта; частота экрана не равна частоте нейронных шагов.

Редактор защищает клетки юнитов и целей и сохраняет связность карты.
Официальные способности и отдельные бойцы внутри отряда не моделируются.

## Сохранения

Формат **v5**, до 8 МБ: карта, RNG, профили, направление взгляда, нейронная активность,
история сигнала и состояние старого рефлекса. Продолжение в v5 воспроизводится точно.
Сохранение — снимок состояния; исторический журнал после загрузки начинается заново.

Сцены v1–v4 загружаются с сообщением о переходе на правила v5.
У v3/v4 сохраняются нейронная память, контактная сцена и фаза рефлекса.
У v2 сохраняется память, рефлекс начинается с готового состояния.
У v1 остаётся обычная тактика. Взгляд старых сцен: A на восток, B на запад.
Миграция не обещает прежнюю будущую траекторию по старым правилам.

Сброс возвращает к исходной или импортированной сцене. Новый бой создаётся
кнопкой «Создать поле». Изменения профиля до первого такта включаются в исходный
снимок; после начала боя они не перезаписывают его.

## Архитектура и аппаратный задел

| Файл | Назначение |
|---|---|
| dist/data/malecns-motor.mjs | Расширенная анатомия, packed CSR, калибровка и SHA-256 |
| dist/motor.mjs | Независимая от игры динамика, моторный декодер, валидация памяти |
| dist/data/malecns-escape.mjs | Компактная анатомия старого рефлекса |
| dist/neural.mjs, dist/reflex.mjs | Диспетчер моделей и отдельный игровой ограничитель рефлекса |
| dist/engine.mjs | RNG, карта, наблюдения, команды, бой и сохранения без DOM |
| dist/experiments.mjs | Изолированные причинные сравнения |
| dist/app.mjs | Canvas, инспектор, управление |
| scripts/import-motor.mjs, scripts/import-malecns.mjs | Воспроизводимое извлечение |
| tests/ | Проверки движка, сетей и адаптеров |

    const state = createSimulation({
      seed: '40721',
      controllerA: 'neural',
      controllerB: 'neural'
    });
    stepSimulation(state);
    const restored = importScene(exportScene(state));

Для совместимости вызов createSimulation без режимов пока сохраняет старый
гибридный режим; интерфейс явно включает neural для обеих сторон.
decideUnit возвращает намерение и не продвигает время. В новом режиме source
равен motor, command содержит выбранную команду, motor — выходы и оценки,
alternatives — доступные и исключённые действия. counterfactual равен null.

stepSimulation продвигает наблюдение, сеть и бой. Необязательный наблюдатель
stepSimulation(state, (decision, unit, board) => { ... }) получает решение
до исполнения, в том числе если юнит погибнет позже в этом такте;
наблюдатель не должен менять объекты.

Для устройства можно отдельно подавать четыре сенсорных значения в stepMotorBrain
и читать команды motorReadout. Игровое состояние не должно подменять подтверждённое
перемещение реального устройства. Камера, моторы и сетевой протокол пока не подключены.

Первая аппаратная версия — камера/метки и ручное исполнение команд. Затем —
калибровка координат, задержки и доверие наблюдениям, подтверждение перемещения,
границы поля и остановка при потере связи. Расширенная JS-модель рассчитана на
компьютер; готового порта на ESP32 нет. Память и задержку нужно измерять на выбранном
железе, либо оставить вычисления на компьютере, а микроконтроллеру передавать команды.
