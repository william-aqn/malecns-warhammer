# Полный MaleCNS и сенсорная лаборатория — 0.10

Новый приоритет: сначала анатомический охват, сенсорная среда и тело, затем
исследования обучения. Новый режим `/lab.html` не содержит обучаемого выходного
слоя, наград, памяти посещений или боевой тактики. Старая тактическая песочница
и её сохранения совместимы с прежней версией.

**Полный аннотированный граф уже подключён. Полноценная биологическая модель
организма ещё не завершена.** Наличие всех рёбер не восстанавливает неизвестные
рецепторы, чувствительность клеток, мышцы и мембранные параметры.

## Запуск

Из каталога репозитория:

```powershell
npm start
```

Открыть http://127.0.0.1:4177/lab.html. На этом компьютере полный набор уже собран. В Windows можно также запустить
`start-lab.cmd` двойным щелчком и оставить его окно открытым.
При новом клонировании нужны Node.js, Python 3.12+ и uv:

```powershell
npm run data:full -- --download
npm start
```

Команда использует закреплённые pyarrow 26.0.0 и numpy 2.5.4. При собственном Python
с этими пакетами можно запустить `python scripts/build-full-cns.py --download`.
Импорт сначала проверяет SHA-256 всех исходников. Существующий повреждённый
исходник автоматически не заменяется. Ссылки закреплены по generation объекта
Google Storage, а не по изменяемому имени latest.

Исходные четыре таблицы занимают около 1.9 ГБ. Производный граф — 206 МБ,
аннотации — 73 МБ; для HTTP есть сжатые копии. Большие файлы находятся в `.cache`,
не включаются в Git и воспроизводятся импортёром. В Git хранятся код, исходные
идентификаторы, манифест и результаты проверки. Для сборки и запуска нужен запас
памяти; диагностический Node-процесс использовал около 1.1 ГБ после сохранений.
Полный режим не встраивается в автономный 12-МБ HTML и пока не предназначен для ESP32.

## Что именно стало полным

В официальных аннотациях выбираются все строки с непустым `superclass` и
`status != Glia`, в порядке bodyId. Никакого отбора по классу, длине пути,
силе связи или близости к выбранному двигательному выходу нет. При этом исходный
официальный снимок уже имеет фильтр minconf-0.5; отброшенные авторами контакты
не восстанавливаются.

| Параметр | Значение |
|---|---:|
| Нейроны | 166 700 |
| Направленные рёбра между выбранными нейронами | 25 582 938 |
| Синаптические контакты на этих рёбрах | 124 177 617 |
| Сохранённые петли нейрона на себя | 101 |
| Клетки со статистикой pre/post/downstream | 166 576 |

| Восходящие нейроны | 1 846 |
| Нисходящие нейроны | 1 314 |
| Моторные клетки VNC | 708 |

«Полный» относится к этой аннотированной популяции. Исходная таблица связей
содержит также множество неразмеченных сегментов и фрагментов. Их нельзя считать
дополнительными идентифицированными нейронами. 44 877 строк аннотаций и
126 273 746 сегментных рёбер вне выбранной популяции исключены явно. Полные
счётчики исключений находятся в `data/full-cns-manifest.json`.

Для каждой клетки сохранены все поля исходных аннотаций: типы, класс и подкласс,
стороны, нервы, нейромеры, линии происхождения, somaLocation, hex-координаты,
receptorType, синонимы и остальные поля. Присоединены все нейромедиаторные поля
и статистика сегмента. `receptorType` здесь является исходной аннотацией
сенсорных клеток; это **не** карта постсинаптических рецепторов всего мозга.

Идентичность графа SHA-256:
`5d7159275c55055ad3d80952531350a018b0483847b5878450ccfac0ad9be509`.
В бинарном CSR хранятся исходные uint32 числа контактов. Float32 коэффициенты
вычисляются отдельно. Исходная анатомия не меняется при шагах, выключении чувств,
смене знаков, сохранении или гипотезах о модуляторах.

## Как среда доходит до клеток

Среда двумерная с высотами стен и объектов для лучей зрения. На каждом такте:
обновляются физические поля и движущиеся стимулы; вычисляются сенсорные входы;
сеть выполняет четыре подшага; моторные группы воздействуют на тело. Новое
движение влияет на следующий сенсорный кадр. Временные и пространственные
единицы условные, а не миллисекунды и миллиметры настоящей мухи.

| Модальность | Подключено клеток | Внешний сигнал |
|---|---:|---|
| Зрение | 5 895 | Фотоны в колонках двух глаз, три условных спектральных диапазона |
| Обоняние | 2 635 | Локальная концентрация выбранного канала ORN; 53 доступных типа |
| Вкус / контактная химия | 1 011 | Контакт вещества с размеченными пробами ног или рта |
| Осязание | 2 557 | Контакт проб тела и ног со стенами / предметами |
| Звук | 114 | Огибающая сигнала у проб антенн, затухание с расстоянием и преградами |
| Механика антенн | 475 | Направление ветра и вращение тела; гравитационная механика не восстановлена |
| Проприоцепция | 901 | Углы, изменения углов, нагрузка ног; вращение для группы haltere |
| Температура | 25 | Локальное скалярное поле температуры |
| Влажность | 66 | Локальное скалярное поле влажности |
| **Всего** | **13 679** | Из 17 937 клеток сенсорных суперклассов |

Соответствие модальности определяется полями class/subclass/entryNerve/side.
Неизвестные клетки не получают случайный сенсорный тип. 4 258 клеток остаются
без внешнего порта, продолжая участвовать в анатомической сети. В интерфейсе
есть разбивка этого остатка. Например, ещё не определены полноценные входы для
крыльев, пищеварительного тракта и многих механочувствительных групп.

Запахи распространяются диффузией, с переносом ветром и распадом. Стена задаёт
непроницаемую границу; сигнал может обойти её через проход. Название ORN задаёт
искусственный адресуемый химический канал, **не** измеренную чувствительность
к натуральной молекуле. Температура, влажность, звук и вкус также имеют явные
упрощённые преобразования; их биологические кривые настройки не восстановлены.

### Зрение без четырёх готовых чисел

В источнике размечены 879 колонок левого глаза и 892 правого. У фоторецепторов
собственных assignedOlHex1/2 нет. Их поле восстанавливается по исходящим
контактам к клеткам того же глаза с размеченными колонками. Сохраняются все
кандидаты и их количества контактов: вход фоторецептора является взвешенным
сигналом этих колонок. Сохраняется dominantShare для оценки неоднозначности.
Это вывод из связности, а не измеренная оптика сетчатки.

5 895 из 6 091 фоторецептора получили такое соответствие; 196 остались без него.
Порядок bodyId нигде не используется для назначения пикселя. Плоские hex-координаты
проецируются на два условных поля зрения шириной 190° и высотой 140°, с центрами
по ±85°. Эта проекция и её ориентация требуют отдельной калибровки.

Каждый луч возвращает UV, синий и зелёный каналы. Стены перекрывают объекты;
есть пол, фон и высоты. R1–R6 получают смесь диапазонов, R7 и DRA — UV,
R8p — синий, R8y — зелёный. Для неопределённых R7/R8 используется явно условная
равная смесь. Точные спектры, поляризация и различия UV-подтипов ещё не моделируются.
Это собственные спектральные значения синтетического мира, а не выдача RGB за UV.

В сеть подаются фоторецепторные входы, а не метки «враг», «угроза», «цель» или
расстояние до препятствия. LC4/LPLC2/LC10 в новом режиме не стимулируются напрямую.
Визуальная картинка в UI показывает вход, но не доказывает распознавание объектов.

## Динамика, химия и тело

Каждый контакт нормирован полным входящим количеством контактов адресата из
исходного сегментного графа. Отсутствующие источники вносят ноль; удаление
фрагментов не усиливает оставшиеся связи перенормировкой.

По умолчанию ACh имеет знак +, GABA/Glu/гистамин — знак −; для Glu есть контроль
с положительным знаком. Неизвестные метки не получают быстрый эффект. Скорость
активности неотрицательна. Фоновый тонус 0.12 позволяет наблюдать подавление
при работе тормозных зрительных путей; это инженерное допущение, не измеренный
фон клетки. Есть отключение рёбер и возможность обнулить тонус.

Дофамин, октопамин и серотонин имеют отдельные медленные состояния у адресатов
существующих связей, с накоплением и затуханием. По умолчанию они только наблюдаются:
рецепторные коэффициенты равны нулю. Пользователь может включить гипотезу влияния
на усиление входа коэффициентом от −2 до +2. Это не концентрации в биологических
единицах и не восстановленная рецепторная физиология. Обучение от них не запускается.

В наличии 708 клеток VNC motor; 381 из них по подклассам fl/ml/hl и стороне
подключены к шести условным приводам ног (68/67/58/58/66/64). Средняя активность
групп задаёт движение и поворот кинематического тела. Контакты со стенами
останавливают движение. Это ещё не карта мышц, реальных суставов и антагонистов.
Остальные моторные группы участвуют в сети и доступны для инспекции, но не
управляют отсутствующими частями тела. Тело по умолчанию зафиксировано; можно
освободить его или вручную сдвинуть для проверки обратной связи.

## Что считать завершением интеграции перед обучением

1. **Анатомический охват — выполнен для аннотированного графа.** Четыре исходные
   таблицы закреплены, проверены и присоединены; известны исключения.
2. **Сенсорные входы — частично.** Есть пространственный вход и девять модальностей;
   требуется закрыть 4 258 неподключённых сенсорных клеток обоснованными моделями
   органов либо явно оставить недоступные в конкретном воплощении.
3. **Функциональное зрение — ещё не доказано.** Нужны тесты яркости, контраста,
   движения в разные стороны, looming, спектров, временной адаптации и сравнение
   ответов конкретных клеток с экспериментальными данными. Анатомическая цепочка
   сама по себе не гарантирует эти функции при выбранной rate-модели.
4. **Тело и моторные петли — частично.** Нужны мышцы/суставы и отдельные функции
   крыльев, шеи, брюшка, питания; верификация проприоцепции и моторных программ.
5. **Морфология и отдельные синапсы — не подключены к динамике.** Координаты сом
   сохранены. Ветви SWC, положения каждого контакта, ROI и пресинаптические NT-
   вероятности доступны в источнике, но требуют отдельного пространственного
   импортёра и модели компартментов/задержек. Простое хранение этих файлов не
   означало бы их использование в вычислении.
6. **Физиология — не завершена.** Неизвестны индивидуальные мембранные параметры,
   постсинаптические рецепторы, реальные задержки и медленная химия; нет спайковой
   модели, нейропептидов и реконструированных электрических связей. Часть этих
   сведений отсутствует в самом MaleCNS и потребует внешних исследований.
7. **Обучение — отложено.** Вернуться после причинных тестов вход → сеть → тело,
   чтобы обучаемая тактика не скрывала дефекты сенсорной или двигательной модели.

Следующий приоритет — проверка зрительных преобразований и моторной реакции,
затем расширение тела и закрытие явно перечисленных сенсорных пробелов. Это
проверки качества восприятия, а не обучение выигрывать бой.

## Проверки

`npm test`: 118 тестов, включая сохранённую совместимость тактического режима.
`npm run benchmark:full` загружает реальный полный граф, проверяет все SHA,
сравнивает отсутствие входов / только зрение / все чувства / отключённые связи,
проверяет точный повтор после сохранения и 180 тактов свободного тела.

В проверенном прогоне изменение зрения доходит до VNC, но эффект слаб:
максимальное изменение активности vnc_intrinsic около 2.76e−5 относительно
контроля без сенсорных входов. Это свидетельство передачи сигнала, не полезного
управления телом и не биологической достоверности. Сохранения занимают около 7 МБ.
Числа и условия записаны в `data/full-cns-benchmark.json`.

`npm run check:full-ui`: HTTP-загрузка, контрольные суммы, протокол фонового потока, элементы управления
и вызовы Canvas проверяются отдельно. Проверка DOM/Canvas через заглушки не
заменяет визуальный просмотр в настоящем браузере.
